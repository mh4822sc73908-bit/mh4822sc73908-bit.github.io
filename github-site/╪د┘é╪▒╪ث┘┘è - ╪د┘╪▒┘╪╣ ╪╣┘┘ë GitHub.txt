نسخة GitHub — موقع المدرسة المركزية للبنين بحائل
================================================

ارفع محتوى هذا المجلد كما هو (وليس المجلد الأصلي «موقع المدرسة المركزية»).

خطوات الرفع
-----------
1) ادخل github.com ← New repository ← اسم مثل: markazia ← Public ← Create.
2) اضغط «uploading an existing file» واسحب كل محتويات هذا المجلد (index.html ومجلدَي assets و docs).
   إذا رفض الرفع لكثرة الملفات، ارفع مجلد docs على دفعات.
3) Commit changes.
4) Settings ← Pages ← Source: Deploy from a branch ← Branch: main و / (root) ← Save.
5) بعد دقيقة يعمل الرابط: https://mh4822sc73908-bit.github.io/markazia/

الدخول
------
- اسم المستخدم = السجل المدني، وكلمة المرور = السجل المدني نفسه.
- زر «الدخول كزائر» يفتح الصفحات العامة دون حساب.

الصلاحيات
---------
زائر: الرئيسية، عن المدرسة، أدلة الطالب والأسرة والموجهين، المؤشرات، الأنشطة، المبادرات، الجداول.
طالب: ما يراه الزائر + «صفحتي» (إشعاراته الخمسة، غيابه، واجباته، مؤشراته في مدرستي).
معلم: كل الأقسام + إضافة الشواهد والدورات في ملفه فقط + إشعارات طلابه فقط.
مشرف تربوي: كل الأقسام عرضًا فقط، دون الإشعارات الفردية للطلاب.
مدير المدرسة: كل الأقسام عرضًا + جميع إشعارات الطلاب + الملفات الإدارية.
مدير الموقع (محمد هليل): كل الصلاحيات.

ما الذي يحمي البيانات؟
----------------------
- أرقام الهوية غير مكتوبة في أي ملف؛ المخزّن بصمات مشفّرة فقط (assets/js/users.js).
- إشعارات الطلاب والملفات الإدارية مخزّنة مشفّرة في docs/secure ولا تُفتح إلا بعد الدخول بصلاحية مناسبة.
- الحماية بقدر سرّية رقم السجل المدني: من يعرف رقم شخص يستطيع الدخول بحسابه.
- الشواهد والدورات التي يضيفها المعلم تُحفظ في جهازه فقط (يلزم Supabase مستقبلًا لحفظها للجميع).

تحديث الحسابات أو الإشعارات
---------------------------
الحسابات والإشعارات مولّدة ومشفّرة آليًا؛ لإضافة مستخدم أو جولة إشعارات جديدة اطلب إعادة توليد النسخة.
